# retail-price-optimization
A dashboard that recommends revenue-maximizing prices using historical sales data.

## Features

Price recommendation
Revenue estimation
Risk analysis
Interactive dashboard

## Pain Points
1. Ignoring the substitution effect
2. Ignoring price elasticity
3. No statistical significance

## Price Strategy
1. Find Lowest competitor price
2. Optimal price and thus maximized total revenue after implement price recommendation for each product
3. ±15% risk boundary
4. Bootstrap validation-confidence interval for the increase in total revenue

## Interactive Dashboard
contains
1. Current Price 
2. Recommended Price
3. Expected Revenue
4. Confidence
5. Risk level

## Business Impact
1. Revenue upside
2. Statistical-based decisions
3. Risk control
